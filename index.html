FAQ

Frequently Asked Questions

What's the best mode for tattoo stencils?

Canny mode is best for tattoo stencils — it produces clean, continuous outlines. Set Low Threshold around 15–30 to capture fine details, High Threshold around 50–80. Increase Line Thickness to 2–3 for thermal printer output.

How do I get results like the red line art shown?

Select Canny mode, set Output Color to Tattoo Red, enable Bilateral Filter, and increase Line Thickness to 2. For highly detailed images, lower the Low Threshold to 10–15.

What does the AI mode do?

AI mode sends your image to Gemini API (using your free API key from Google AI Studio) which analyzes the image content and automatically sets the optimal Canny thresholds, blur level and line thickness for a tattoo-quality stencil.

Is my image uploaded to any server?

In standard modes (Canny/Sketch/Threshold), all processing is 100% local in your browser. In AI mode only, your image is sent to Google's Gemini API for analysis — your API key and data are governed by Google's privacy policy.

What resolution will my stencil be?

The stencil matches your original image resolution (up to 900px display width). For best results, use images of at least 1500×1500px.

What's the difference between Canny and Threshold modes?

Canny traces only the actual edges in the image using gradient analysis — ideal for clean line art outlines. Threshold cuts all pixels above/below a brightness value — works well for high-contrast images. Sketch combines both.
